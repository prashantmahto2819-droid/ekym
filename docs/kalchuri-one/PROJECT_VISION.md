# KALCHURI ONE — Project Vision

**एक प्लेटफ़ॉर्म। हर संगठन। हर परिवार। हर सदस्य।**

## यह क्या है
Kalchuri One कलचुरी (कलार) समाज और उससे जुड़े हर संगठन (राष्ट्रीय → प्रदेश → ज़िला → तहसील → शहर → स्थानीय), ट्रस्ट, फ़ाउंडेशन, समिति, परिवार और व्यापार के लिए एक साझा डिजिटल ऑफ़िस है।

हर संगठन को एक ही जगह मिलेगा:

| ज़रूरत | Kalchuri One में |
|---|---|
| अपनी वेबसाइट | संगठन की अपनी साइट (`संगठन.kalchurione.in` या अपना डोमेन), CMS से बिना तकनीकी मदद के बदलें |
| सदस्य व समिति | सदस्यता आवेदन, डिजिटल कार्ड, पदाधिकारी, कार्यकाल, बैठक, कार्यवृत्त, प्रस्ताव |
| पत्र व्यवहार | लेटरहेड, पत्र, नोटिस, प्रमाणपत्र → स्वीकृति → PDF → WhatsApp/ईमेल → रजिस्टर |
| हिसाब-किताब | रसीद, वाउचर, बिल, double-entry खाते, वित्तीय वर्ष, रिपोर्ट |
| प्रकाशन | ब्लॉग, समाचार, पत्रिका (flipbook), वार्षिक रिपोर्ट |
| आयोजन | कार्यक्रम, निमंत्रण पत्र, RSVP, उपस्थिति |
| समाज सेवा | शोक संदेश, वंश वृक्ष, रक्तदाता, छात्रवृत्ति, रोज़गार, वैवाहिक, व्यापार निर्देशिका |
| संवाद | WhatsApp/ईमेल अभियान, सहमति रिकॉर्ड, डिलीवरी रिपोर्ट |

## तीन आधार-स्तंभ (design principles)
1. **एक Design Engine**: लेटरहेड, पत्र, निमंत्रण, प्रमाणपत्र, रसीद, सदस्यता कार्ड, पोस्टर, शोक पत्र और पत्रिका कवर, सब एक ही इंजन से बनें। हर एक के लिए अलग सॉफ़्टवेयर नहीं बनेगा। इसका बीज शोकपत्र ऐप के `studio-engine.js` में पहले से मौजूद है।
2. **एक Document Workflow**: `बनाओ → स्वीकृति → जारी (नंबर + QR) → भेजो → संग्रह`। पत्र, रसीद, प्रमाणपत्र और निमंत्रण सब इसी रास्ते से चलते हैं। रसीद जारी होते ही हिसाब में entry अपने आप बनती है।
3. **एक संवाद इंजन (Communication Engine)**: सारे WhatsApp/ईमेल संदेश एक ही कतार (queue) से जाते हैं। provider बदला जा सकता है (Vivid Relay / Meta Cloud API / SMTP)। सहमति, retry, लागत और रिपोर्ट एक जगह रहती है।

## किसके लिए
- **Super Admin** (प्लेटफ़ॉर्म मालिक): सभी संगठन, स्वीकृति, साझा टेम्पलेट, विज्ञापन, सेटिंग।
- **संगठन एडमिन / विभाग एडमिन**: अपने संगठन का सब कुछ, या सिर्फ़ सौंपे गए विभाग।
- **सदस्य**: अपनी प्रोफ़ाइल, परिवार, लेख लिखना, आयोजन, शोक संदेश।
- **आम जनता**: संगठनों की वेबसाइट, समाचार, पत्रिका, निर्देशिका।

## सफलता का पैमाना (पहला साल)
- पहला संगठन (एकात्म कलार युवा मंच) पूरी तरह Kalchuri One पर चल रहा हो।
- कम से कम 10 संगठन अपनी साइट, सदस्य और रसीदें यहीं से चला रहे हों।
- शोकपत्र सेवा का सारा मौजूदा डेटा (परिवार, सदस्य, क्षेत्र) बिना नुकसान के Kalchuri One में हो।
- कोई भी गैर-तकनीकी कार्यकर्ता बिना मदद के पत्र बनाकर भेज सके।

## गैर-लक्ष्य (शुरुआत में नहीं)
- कानूनी रूप से बाध्य चुनाव (शुरू में "आंतरिक मतदान/राय" ही)।
- CA-ऑडिट या GST रिटर्न फ़ाइलिंग का विकल्प। हिसाब मदद के लिए है, statutory compliance की ज़िम्मेदारी संगठन की रहेगी।
- हर विज्ञापन पर पूरा नियंत्रण। AdSense में Google के अपने नियम और सीमाएँ हैं।
